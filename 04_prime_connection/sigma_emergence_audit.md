# Sigma Emergence Audit

## 목적

리만 가설의 `Re(s)=1/2`를 사전에 넣지 않고, 기존 형성/속성 자료를 복소화했을 때 어떤 실수부 `sigma`가 절단범위 증가에 따라 스스로 안정화되는지 검사한다.

핵심 원칙:

- `1/2`를 목표값, 대칭점, 정규화 기준으로 사용하지 않는다.
- 단순 누적합 안정도는 큰 `sigma`가 꼬리를 자동 억제하므로 그대로 사용하지 않는다.
- dyadic shell `(2^(k-1), 2^k]` 안에서 위치를 `x=n/2^k`로 재스케일한다.
- 같은 `sigma`에서 무구조 기준 `f(n)=1`을 빼서 `n^{-sigma}` 자체가 만드는 형상을 제거한다.
- 최적 `sigma`가 절단범위와 shell 선택에 따라 이동하는지 반드시 추적한다.

---

## 1. Shell 복소 프로필

관측량 `f(n)`에 대해

\[
H_{f,k}(\sigma,t)
=
\frac{\sum_{2^{k-1}<n\le2^k}f(n)n^{-\sigma}
\exp[-it\log(n/2^k)]}
{\sum_{2^{k-1}<n\le2^k}f(n)n^{-\sigma}}
\]

를 정의한다.

무구조 기준은

\[
H_{1,k}(\sigma,t)
\]

이고, 잔차 프로필은

\[
R_{f,k}(\sigma,t)
=H_{f,k}(\sigma,t)-H_{1,k}(\sigma,t)
\]

이다.

인접 shell 안정도는

\[
S_{f,k}(\sigma)
=
\frac{
\left\|R_{f,k+1}(\sigma,\cdot)-R_{f,k}(\sigma,\cdot)\right\|_2
}{
\left\|R_{f,k}(\sigma,\cdot)\right\|_2
}
\]

로 두었다.

이 정의에는 `1/2`가 들어가지 않는다.

---

## 2. 사용 관측량

- `omega(n)`: 서로 다른 소수채널 수
- `Omega(n)`: 중복을 포함한 소수채널 총수
- `W(n)`: composite-only ordered prime formation-word count

`W(n)`은 기존 형성단어 정의와 동일하며 소수 자체는 비자명 형성으로 세지 않는다.

계산 범위는 최대 `2^19=524288`까지 사용했다.

---

## 3. 1차 결과: 공통 고정점 없음

최근 큰 shell들의 상대 안정도를 비교했을 때:

- `omega`: 최저 영역이 대략 `sigma≈0.5~0.6` 부근에 나타나는 경우가 있었으나 곡선이 매우 평평했고 shell 범위를 바꾸면 이동했다.
- `Omega`: 작은 `sigma` 쪽으로 최저점이 이동하는 경우가 많았다.
- `W`: 중간 범위에서는 `sigma≈0.5`가 일시적으로 최적이었으나 더 큰 shell을 포함하면 큰 `sigma` 방향으로 이동했다.

따라서

\[
\boxed{
\text{현재 정의에서는 }\sigma=1/2\text{로 수렴하는 공통 안정점이 확인되지 않았다.}
}
\]

이 결과는 RH에 대한 부정적 결과가 아니라, 현재의 독립 진단량이 아직 RH와 직접 연결되지 않았다는 뜻이다.

---

## 4. 가장 중요한 가짜 양성 사례: W

`W(n)`의 shell 잔차 안정도는 일부 범위에서 `sigma=0.5`를 최적으로 선택했다.

그러나 같은 계산을 더 큰 절단까지 연장하면 최적점이 이동했다.

대표 결과:

| 최대 shell 상단 N | 최적 sigma | 상대 안정도 점수 |
|---:|---:|---:|
| 16,384 | 0.50 | 0.143709 |
| 32,768 | 0.20 | 0.088313 |
| 65,536 | 0.20 | 0.053072 |
| 131,072 | 0.45 | 0.036850 |
| 262,144 | 0.90 | 0.028129 |
| 524,288 | 0.90 | 0.024430 |

따라서 `N=16384`까지만 보았다면

\[
\sigma_*=1/2
\]

라는 매우 매력적인 결론을 잘못 내릴 수 있었다.

이 사례를 앞으로 모든 `1/2` 후보에 적용할 **positive-looking false-control**로 보존한다.

---

## 5. omega의 최적점 이동

더 촘촘한 `sigma` 격자에서 `omega`의 최적점을 절단범위별로 추적하면 예를 들어 다음처럼 이동했다.

| 최대 N | 최적 sigma |
|---:|---:|
| 16,384 | 0.74 |
| 32,768 | 0.80 |
| 65,536 | 0.54 |
| 131,072 | 0.20 |
| 262,144 | 0.20 |
| 524,288 | 0.64 |

고정된 내부 극한을 지지하지 않는다.

`Omega` 역시 같은 범위에서 안정된 내부 `sigma_*`를 보이지 않았다.

---

## 6. 감사 결론

현재 단계에서 다음 주장을 기각한다.

1. 복소 형성자료가 자동으로 `sigma=1/2`를 선택한다.
2. 중간 절단범위에서 `1/2`가 최적이라는 사실만으로 구조적 의미를 부여한다.
3. shell 안정도 최소점 자체를 제타 영점의 실수부와 동일시한다.

반대로 다음 조건을 향후 필수조건으로 둔다.

\[
\boxed{
\sigma_N^*\to\sigma_*\quad(N\to\infty)
}
\]

후보를 인정하려면

- 여러 관측량 또는 독립적으로 정당화된 단일 관측량에서 안정해야 하고,
- shell 시작점/끝점 변경에 안정해야 하며,
- `t` 탐색범위 변경에도 안정해야 하고,
- 무구조 기준 제거 방식 변경에도 안정해야 하며,
- 유한 절단 가짜 양성 `W@N=16384`를 통과해야 한다.

---

## 7. 다음 단계

무작정 새 목적함수를 만들어 `1/2`를 찾는 것은 중단한다.

다음은 정확한 생성함수 구조를 사용한다.

\[
F_W(s)=\frac{P(s)^2}{1-P(s)}
\]

및

\[
\mathcal T(s)=P(s)+\frac12\left(\mathcal T(s)^2+\mathcal T(2s)\right).
\]

여기서 해야 할 일은:

1. `P(s)`가 이미 전달하는 zeta 정보와 형성구조가 새로 만드는 구조를 분리한다.
2. `P(s)`의 특이점을 제거하거나 표시한 뒤 `W,T`의 추가 특이/안정 구조를 검사한다.
3. 특히 `T(2s)` 재귀가 단순한 조합론적 스케일 복제인지, 별도의 분석적 제약을 만드는지 감사한다.
4. 어떤 후보도 `sigma=1/2`를 사전에 삽입하지 않은 상태에서만 평가한다.

현 단계의 결론은 **`1/2`를 발견하지 못했다**가 아니라, **`1/2`처럼 보이는 유한범위 가짜 양성을 실제로 하나 확보했고 이를 배제하는 감사 기준을 세웠다**는 것이다.
