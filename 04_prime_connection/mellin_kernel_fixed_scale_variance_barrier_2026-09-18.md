# Mellin kernel fixed-scale variance barrier — 2026-09-18

## Status
- Riemann hypothesis: OPEN.
- Context: critical Vaughan-edge / long-Möbius Type-II block after Mellin separation.

- Classification: `RECIPROCAL_MELLIN_KERNEL_FIXED_SCALE_BARRIER`.

## 1. Starting long-polynomial correlation

For a smooth `t`-window centered at `T` of length `X`, expansion of

\[
\int W\!\left(\frac{t-T}{X}\right)
\left|\sum_{n\asymp L}\mu(n)n^{it}\right|^2dt
\]

gives

\[
X\sum_{m,n\asymp L}
\mu(m)\mu(n)
e^{iT\log(m/n)}
\widehat W\!\left(X\log\frac mn\right).
\]

Put `m=n+h`. Rapid decay of `\widehat W` restricts the effective shift range to

\[
|h|\lesssim Y,
\qquad
Y:=\frac LX.
\]

At the critical reciprocal edge,

\[
X=L^{2/3},
\qquad
Y=L^{1/3}.
\]

## 2. Natural rescaling

Write

\[
n=Lu,
\qquad
h=Yv,
\]

where `u` stays in a fixed compact dyadic interval and `v=O(1)`.

Since `Y=L/X`,

\[
\frac hn
=
\frac{Yv}{Lu}
=
\frac{v}{Xu}.
\]

Therefore

\[
X\log\left(1+\frac hn\right)
=
X\log\left(1+\frac{v}{Xu}\right)
=
\frac vu
-
\frac{v^2}{2Xu^2}
+
O(X^{-2}).
\]

Hence

\[
\boxed{
X\log(1+h/n)
=
\frac vu+O(X^{-1})
}
\]

uniformly for bounded `u,v`.

The Fourier-window factor consequently has the fixed-scale limit

\[
\widehat W\!\left(X\log(1+h/n)\right)
=
\widehat W(v/u)+O(X^{-1}).
\]

## 3. The Mellin center phase also freezes

The stationary Mellin band generated by

\[
G_X(z)=W_0(z)e(Xz^{-1/2})
\]

has center/typical frequencies of size

\[
T\asymp X.
\]

Write

\[
T=\tau X,
\]

with `\tau` confined to a fixed compact interval determined by the dyadic support and the stationary-phase map.

Then

\[
T\log(1+h/n)
=
\tau X\log\left(1+\frac{v}{Xu}\right)
=
\tau\frac vu+O(X^{-1}).
\]

Thus

\[
\boxed{
e^{iT\log(1+h/n)}
=
e^{i\tau v/u}\left(1+O(X^{-1})\right).
}
\]

Again there is no growing oscillatory parameter.

## 4. Limiting kernel

The full off-diagonal weight has the form

\[
K_X(u,v)
=
e^{iT\log(1+h/n)}
\widehat W\!\left(X\log(1+h/n)\right).
\]

The preceding expansions imply

\[
\boxed{
K_X(u,v)
=
K_\infty(u,v)+O(X^{-1}),
}
\]

where

\[
K_\infty(u,v)
=
e^{i\tau v/u}\widehat W(v/u)
\]

is a fixed smooth function independent of `L`.

Therefore the reciprocal phase does not turn the shift variable into an increasingly oscillatory variable after the correct resolution scale `Y=L/X` is imposed.

## 5. Consequence for cancellation claims

The required long-polynomial estimate is equivalent in power scale to controlling

\[
\sum_{|h|\lesssim Y}
\sum_{n\asymp L}
\mu(n)\mu(n+h)
K_X(n/L,h/Y).
\]

Because `K_X\to K_\infty` at fixed scale, no integration by parts or stationary-phase argument in the normalized variables can produce a positive power of `L`.

Any claimed power saving must therefore use arithmetic information in

\[
\mu(n)\mu(n+h),
\]

not merely the smoothness or oscillation of the reciprocal kernel.

Permanent guard:

`FIXED_SCALE_KERNEL_NO_POWER_GAIN`.

## 6. Relation to short-interval variance

The kernel is not identical to the unmodulated triangular short-interval kernel. It includes a fixed modulation `e^{i\tau v/u}` and a smooth profile `\widehat W(v/u)`.

Thus the present target is best described as a **modulated smooth short-shift Möbius variance**, not literally the ordinary variance.

However the modulation changes only by `O(1)` radians across the natural shift range `|h|\lesssim Y`. It is therefore not an asymptotically rapid oscillation capable of explaining the missing polynomial factor.

This preserves the distinction:

- proving ordinary short-interval random variance would be sufficient for this module after standard smooth-weight manipulations;
- the present one fixed modulated kernel may be formally weaker than all unweighted variance estimates;
- but its apparent extra phase is not itself a large-parameter source of cancellation.
