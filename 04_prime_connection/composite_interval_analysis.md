# Composite Interval Structural Analysis

## 목적
연속한 두 소수 사이의 합성수 구간을 하나의 구조적 객체로 분석한다.

연속한 소수 `p_k < p_{k+1}`에 대해

`B_k = {p_k+1, ..., p_{k+1}-1}`

을 합성수 블록(composite interval/block)으로 둔다.

여기서 소수는 '점진적으로 접근되는 값'으로 가정하지 않는다. 소수는 해당 블록을 양쪽에서 끊는 경계/임계 위치로 취급한다.

## 개별 합성수 지표
각 `n in B_k`에 대해 다음을 기록한다.

- prime factorization
- `omega(n)`: 서로 다른 소인수 수
- `Omega(n)`: 중복 포함 소인수 수
- `tau(n)`: 약수 수
- `F_x*(n) = ceil(tau(n)/2)-1`: 자명한 `1*n`을 제외한 순서 없는 비자명 곱셈 형성 수
- `P^-(n)`: 최소 소인수

## 합성성 witness set
합성수 `n`에 대해

`W(n) = { q prime : q | n and q <= sqrt(n) }`

로 둔다.

`W(n)`은 `n`이 합성수임을 증명할 수 있는 소인수 witness들의 집합이다.

## 블록 최소 덮임수
합성수 블록 전체를 설명하는 최소 소인수 채널 수를

`kappa(B_k) = min |Q|`

subject to

`for every n in B_k, there exists q in Q with q in W(n)`

로 정의한다.

이 값은 prime gap 길이와 별개의 내부 구조량이다.

## 중요한 초기 관찰
같은 prime gap 길이라고 해서 내부 합성수 구조가 동일하지 않다.

1000 미만의 연속 소수쌍을 전수 검사한 초기 계산에서 gap=14인 경우:

- 113–127: `kappa=5`, minimum cover `{2,3,5,7,11}`
- 293–307: `kappa=5`
- 317–331: `kappa=6`, minimum cover `{2,3,5,7,11,17}`
- 773–787: `kappa=5`
- 839–853: `kappa=6`
- 863–877: `kappa=5`
- 953–967: `kappa=5`

따라서 `prime gap = 14`만으로는 해당 구간의 합성 형성구조를 결정할 수 없다.

이것은 분석 방향상 중요하다. 이후에는 단순한 소수 간격 `g_k`뿐 아니라

`(g_k, kappa(B_k), mean omega, mean Omega, mean F_x*, witness-cover pattern, residue-cover pattern)`

을 함께 보아야 한다.

## 구조적 해석
합성수 블록은 작은 소수들의 주기적 배수 격자가 겹쳐 만들어진다.

소수 종점에서는 해당 정수 이하의 가능한 비자명 소인수 witness가 존재하지 않는다. 따라서 소수를 '합성수 형성 채널이 점진적으로 감소한 끝'으로 해석하지 않고, '합성수 덮임이 성립하지 않는 경계 위치'로 취급한다.

## 감사 규칙
- `kappa`는 새 정수론적 불변량으로 주장하지 않는다. 현재는 분석용 정의이다.
- 작은 표본에서 발견한 gap-kappa 관계를 일반식으로 승격하지 않는다.
- 동일 gap에서 서로 다른 kappa가 이미 존재하므로 gap만으로 구조를 대표하지 않는다.
- 소수 위치를 미리 알고 구성한 지표와, 소수 위치를 모른 채 계산 가능한 지표를 구분한다.
- 향후 대규모 계산에서는 연속 소수쌍 전체와 무작위 표본을 분리한다.
