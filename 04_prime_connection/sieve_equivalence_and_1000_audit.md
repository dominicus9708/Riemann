# Prime-Channel Model: Sieve Equivalence and 2–1000 Audit

## 1. 목적

`소수 = 새 형성채널의 최초 출현`, `합성수 = 기존 채널들의 중첩`이라는 표현이 표준 정수론에서 어디까지 새로운 내용이고 어디부터 기존 체(sieve) 관점의 재표현인지 감사한다.

동시에 2–100에서 만든 형성단어·형성트리 기준을 2–1000으로 확장하여 구조가 안정적인지 확인한다.

---

## 2. 기존 채널 덮임과 새 채널 사건의 분리

정수 `n >= 2`에 대해 기존 소수채널의 덮임 수를

\[
C_{\mathrm{old}}(n)
=
\#\{p<n:\;p\text{ prime},\;p\mid n\}
\]

라고 둔다.

그러면 정확히

\[
\boxed{
\begin{aligned}
n\text{ prime}
&\Longrightarrow C_{\mathrm{old}}(n)=0,\\
n\text{ composite}
&\Longrightarrow C_{\mathrm{old}}(n)\ge1.
\end{aligned}}
}
\]

새 채널 사건을

\[
G(n)=
\begin{cases}
1,&n\text{ prime},\\
0,&n\text{ composite}
\end{cases}
\]

라고 하면 현재 채널모형에서

```text
prime     : prior overlap = 0, new channel = 1
composite : prior overlap >= 1, new channel = 0
```

으로 분리된다.

이 구분은 `data/formation/prime_channel_vectors_2_100.csv`에 반영했다.

## 3. 에라토스테네스 체와의 동치 감사

합성수 `n`에는 반드시

\[
\exists p\le\sqrt n:\quad p\mid n
\]

인 소수 `p`가 존재한다.

따라서 각 기존 소수 `p`가

\[
2p,3p,4p,\ldots
\]

를 주기적으로 덮는 채널이라고 보면, 기존 채널들에 의해 덮인 위치가 합성수이고 덮이지 않은 다음 위치가 새 소수채널의 출현점이 된다.

이는 이진적인 소수/합성수 판별 수준에서는 본질적으로 **에라토스테네스의 체를 채널 언어로 다시 표현한 것**이다.

### 감사 판정

`새 채널/기존 채널 덮임`만으로는 새로운 소수 판정법이 아니다.

따라서 연구 가치가 생길 수 있는 부분은 다음 추가정보에 한정한다.

1. 한 위치를 동시에 덮는 서로 다른 소수채널 수 `ω(n)`
2. 중복을 포함한 총 채널세기 `Ω(n)`
3. 각 채널의 실제 소수값 `p`
4. 채널의 반복지수 `ν_p(n)`
5. 순서 있는 형성경로 `W(n)`
6. 계층적 형성트리 `T(n)`
7. 정수구간에서 이 자료들을 함께 정적집계했을 때의 구조

즉 **체가 버리는 내부 구조를 보존하는 것**이 현재 실험의 차별점 후보이다.

## 5. 지수패턴 불변성 감사

각 정수의 소인수분해

\[
n=\prod p_i^{e_i}
\]

에서 실제 소수값을 지우고 지수들의 내림차순 패턴

\[
E(n)=\operatorname{sort}(e_1,e_2,\ldots)
\]

만 남겼다.

2–1000에서는 서로 다른 지수패턴이 38개 나타났다.

각 패턴별로 다음 네 값

\[
\bigl(
|W(n)|,\;|T(n)|,\;d_{\min}(n),\;d_{\max}(n)
\bigr)
\]

을 비교한 결과, **같은 지수패턴 안에서 값이 달라지는 사례는 0개**였다.

### 판정

현재 정의의 형성단어 수·형성트리 수·깊이는 실제 소수값보다 소인수 중복 패턴의 조합구조를 측정한다.

따라서

\[
12=2^2\cdot3,
\qquad
18=2\cdot3^2,
\qquad
20=2^2\cdot5
\]

처럼 실제 소수채널이 달라도 지수패턴이 같으면 해당 구조계수는 같다.

이것은 2–100에서 얻은 음성 감사 결과가 2–1000까지 유지된 것이다.

## 8. 정적집계를 위한 다음 원시 행렬

소수채널을 열, 정수 위치를 행으로 두어

\[
M_{n,j}=\nu_{p_j}(n)
\]

인 희소행렬을 기본 구조로 사용할 수 있다.

이 행렬에서 다음 두 집계를 구분한다.

### 채널 점유수

\[
H_j(I)
=
\sum_{n\in I}\mathbf 1_{\nu_{p_j}(n)>0}.
\]

구간 `I`에서 소수채널 `p_j`가 몇 정수에 실제로 참여했는지를 센다.

### 채널 총세기

\[
A_j(I)
=
\sum_{n\in I}\nu_{p_j}(n).
\]

중복지수까지 포함한 누적 채널세기이다.

이 둘은 표준 소인수자료에서 직접 계산되며, 이후 형성단어/트리 채널과 결합하기 전의 **정적집계 원시층**으로 사용한다.

## 9. 다음 단계

1. 소수 `p`를 중심으로 좌우 고정폭 구간의 `H_j`, `A_j`를 계산한다.
2. 같은 폭의 합성수 중심 대조군과 비교한다.
3. 소수 위치를 알고 나서 만든 후향적 지표와, 소수 위치를 사용하지 않은 선행 지표를 분리한다.
4. 차이가 단순한 체 구조에서 자동으로 생기는지 감사한다.
5. 체 구조로 설명되지 않는 잔차만 형성공리계/속성공리계 정적집계 후보로 남긴다.
6. 그 이후에만 소수분포 및 리만 제타함수 관련 통계와 연결한다.
