# Problem Statement

## 1. Standard statement

리만 제타함수의 비자명한 영점 \(\rho\)에 대해

\[
\zeta(\rho)=0,\qquad 0<\operatorname{Re}(\rho)<1
\]

이면 항상

\[
\operatorname{Re}(\rho)=\frac12
\]

인가를 묻는다.

즉

\[
\forall \rho\,\bigl(\zeta(\rho)=0 \land 0<\operatorname{Re}(\rho)<1\bigr)
\Rightarrow \operatorname{Re}(\rho)=\frac12.
\]

## 2. 해결 조건

### 증명
모든 비자명한 영점에 대해 위 함의를 무조건적으로 증명한다.

### 반증
단 하나의 엄밀한 비자명 영점 \(\rho\)에 대해

\[
\operatorname{Re}(\rho)\ne \frac12
\]

임을 증명하면 충분하다.

## 3. 범위 밖의 것

다음은 그 자체로 RH의 증명이 아니다.

- 유한 개수의 영점이 임계선 위에 있다는 계산
- 임계선 위에 무한히 많은 영점이 있다는 증명
- 비자명한 영점의 양의 비율이 임계선 위에 있다는 증명
- 함수방정식에서 얻는 영점 대칭성
- RH를 전제로 얻은 결과를 다시 RH의 근거로 사용하는 순환논증
