# Riemann Hypothesis Analysis & Audit

이 저장소는 리만 가설 자체의 증명 주장보다 먼저, 알려진 정리·영점 데이터·수치 계산·증명 접근을 재현 가능하게 비교하고 감사하기 위한 기준층을 구축한다.

## 연구 순서

1. `00_scope/` — 문제 범위, 표기, 증거 상태 규칙
2. `01_foundations/` — 제타함수 정의, 해석적 연속, Euler product, 함수방정식, xi 함수
3. `02_zero_structure/` — 자명/비자명 영점, 임계띠, 대칭, 임계선
4. `03_zero_distribution/` — N(T), Riemann–von Mangoldt, 영점 밀도·간격
5. `04_prime_connection/` — Λ(n), ψ(x), π(x), 명시적 공식
6. `05_computation/` — Z(t), Riemann–Siegel, 영점 탐색 및 누락 검증
7. `06_equivalent_criteria/` — RH 동치·필요·충분 조건
8. `07_known_partial_results/` — 확립 결과와 최근 프리프린트 분리
9. `08_approach_families/` — 주요 증명 접근군
10. `09_comparative_analysis/` — 접근군 비교와 패턴 분석
11. `10_audit/` — 전제, 논리 사슬, 수치오차, 순환논증, 일반화 오류 감사

## 핵심 원칙

- `증명됨(theorem)`, `조건부 결과`, `수치적 증거`, `휴리스틱`, `추측`을 분리한다.
- 외부 문헌은 인용과 동시에 전제·범위·최신성·오용 위험을 감사한다.
- 계산 데이터는 결과값뿐 아니라 정밀도, 계산법, 완전성/누락 검증법을 기록한다.
- 유한 계산에서 무한 명제로 넘어가는 추론은 별도 증명 없이는 허용하지 않는다.
- 대칭성 자체를 임계선 귀속으로 오인하지 않는다.
- 모든 새 식은 기존 정리와의 충돌, 숨은 RH 의존성, 정의역, 수렴, 극한·합·미분·적분 교환 조건을 검사한다.

## 현재 단계

초기 기준층 구축 중. 증명 접근 비교는 `00_scope`~`05_computation`의 최소 기준선이 형성된 뒤 시작한다.
